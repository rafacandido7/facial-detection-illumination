**Function 1: `compute_iou(boxA, boxB)`**

Implement the intersection-over-union formula exactly as verified in RESEARCH.md Pattern 2:
- xA = max(boxA[0], boxB[0])
- yA = max(boxA[1], boxB[1])
- xB = min(boxA[2], boxB[2])
- yB = min(boxA[3], boxB[3])
- inter = max(0, xB - xA) * max(0, yB - yA)
- areaA = (boxA[2] - boxA[0]) * (boxA[3] - boxA[1])
- areaB = (boxB[2] - boxB[0]) * (boxB[3] - boxB[1])
- union = areaA + areaB - inter
- return inter / union if union > 0 else 0.0

All inputs are (x1, y1, x2, y2) tuples. No coordinate validation needed (caller is always detectors.py output).

**Function 2: `match_detections(gt_boxes, det_boxes, iou_thresh=0.5)`**

Implement the greedy matching algorithm exactly as verified in RESEARCH.md Pattern 2:
- matched_gt = set()
- matched_det = set()
- best_iou = 0.0
- Outer loop: for gi, gt in enumerate(gt_boxes)
- Inner loop: for di, det in enumerate(det_boxes) — skip if di in matched_det
  - Compute iou_val = compute_iou(gt, det)
  - If iou_val >= iou_thresh: add gi to matched_gt, add di to matched_det, update best_iou, break inner loop
  - Always: best_iou = max(best_iou, iou_val)  # track even sub-threshold pairs
- tp = len(matched_gt)
- fp = len(det_boxes) - len(matched_det)
- fn = len(gt_boxes) - len(matched_gt)
- return tp, fp, fn, best_iou

**Function 3: `aggregate_metrics(df)`**

Implement micro-averaged aggregation using pandas groupby exactly as in RESEARCH.md Pattern 2:
- grouped = df.groupby(["detector", "condition", "pass"])[["tp", "fp", "fn", "inference_ms"]].sum()
- grouped["precision"] = grouped["tp"] / (grouped["tp"] + grouped["fp"]).clip(lower=1)
- grouped["recall"] = grouped["tp"] / (grouped["tp"] + grouped["fn"]).clip(lower=1)
- p = grouped["precision"]
- r = grouped["recall"]
- grouped["f1"] = 2 * p * r / (p + r).clip(lower=1e-9)
- grouped["mean_ms"] = grouped["inference_ms"] / df.groupby(["detector", "condition", "pass"]).size()
- return grouped.reset_index()

CRITICAL: Do NOT add print statements, logging, or any I/O to any of these functions. They are pure math transforms.
