**`load_ground_truth(json_path)` function:**

Implement exactly as RESEARCH.md Pattern 3:
- Open json_path and parse with json.load()
- Build a dict: key = entry["file"] (string), value = {"condition": entry["condition"], "faces": [(face["x1"],face["y1"],face["x2"],face["y2"]) for face in entry["faces"]]}
- Return the dict

**`main()` function — argparse setup:**

Use argparse.ArgumentParser with description "Avaliação batch: Haar | HOG+SVM | YuNet com e sem CLAHE":
- `--dataset-dir` (required): str, help="Diretório com imagens (percorrido recursivamente)"
- `--gt-file` (optional, default=None): str, help="JSON de ground truth (omitir para modo timing-only)"
- `--out-dir` (optional, default="results"): str, help="Diretório de saída para os CSVs"
- `--iou-thresh` (optional, default=0.5, type=float): help="Limiar IoU para TP/FP/FN"

**`main()` function — setup before batch loop:**

1. If not MODEL_PATH.exists(): call download_yunet()
2. Load GT if args.gt_file is not None: gt = load_ground_truth(args.gt_file)
   Else: gt = None
3. dets = init_detectors()  # called ONCE here, not inside the loop
4. DETECT_FNS = {"haar": (detect_haar, dets["haar"]), "hog": (detect_hog, dets["hog"]), "yunet": (detect_yunet, dets["yunet"])}
5. images = sorted(Path(args.dataset_dir).rglob("*.jpg"))
6. If len(images) == 0: print error to stderr, sys.exit(1)
7. dataset_name = Path(args.dataset_dir).name
8. out_dir = Path(args.out_dir) / dataset_name
9. out_dir.mkdir(parents=True, exist_ok=True)
10. records = []

**`main()` function — batch loop:**

```python
for img_path in tqdm(images, desc="Evaluating", unit="img"):
    img = cv2.imread(str(img_path))
    if img is None:
        continue  # skip unreadable images, do NOT sys.exit

    img_clahe = apply_clahe(img)
    condition = img_path.parent.name

    # Normalize path for GT lookup (relative to project root)
    rel_path = str(img_path.relative_to("."))
    gt_entry = gt.get(rel_path) if gt else None
    gt_boxes = gt_entry["faces"] if gt_entry else []

    for pass_name, pass_img in [("raw", img), ("clahe", img_clahe)]:
        for det_name, (detect_fn, det_obj) in DETECT_FNS.items():
            boxes, ms = detect_fn(pass_img, det_obj)

            if gt_entry is not None:
                tp, fp, fn, best_iou = match_detections(gt_boxes, boxes, args.iou_thresh)
            else:
                tp, fp, fn, best_iou = float("nan"), float("nan"), float("nan"), float("nan")

            best_det = boxes[0] if boxes else (None, None, None, None)
            best_gt = gt_boxes[0] if gt_boxes else (None, None, None, None)

            records.append({
                "image_path":   str(img_path),
                "condition":    condition,
                "detector":     det_name,
                "pass":         pass_name,
                "gt_x1":        best_gt[0],  "gt_y1": best_gt[1],
                "gt_x2":        best_gt[2],  "gt_y2": best_gt[3],
                "det_x1":       best_det[0], "det_y1": best_det[1],
                "det_x2":       best_det[2], "det_y2": best_det[3],
                "iou":          best_iou,
                "tp":           tp,
                "fp":           fp,
                "fn":           fn,
                "inference_ms": ms,
                "n_detections": len(boxes),
                "n_gt_faces":   len(gt_boxes),
            })
```

**After the batch loop:**
